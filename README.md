# Anonymous ICRA Submission Website

This repository hosts an anonymous project website for an IEEE ICRA submission.

## Website contents

- `index.html`: landing page with embedded/linked videos and supporting material links.
- `assets/videos/`: submission videos (e.g., teaser, main video, ablations).
- `assets/materials/`: supplementary files (e.g., PDF, appendix, additional figures).

## Usage

1. Add video files under `assets/videos/`.
2. Add supporting files under `assets/materials/`.
3. Update file links in `index.html` if filenames differ from defaults.
4. Host as a static site (for example with GitHub Pages).
